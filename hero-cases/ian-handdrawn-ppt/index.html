怎么获取这两个 key？

本 hero case 默认用以下供应商（也接受其他 OpenAI 兼容 endpoint）：

  • LLM 推理：StepFun（https://api.stepfun.com/v1）或 DeepSeek（https://api.deepseek.com/v1，model deepseek-chat）。任何兼容 OpenAI /chat/completions 的服务都行。
  • 图像生成：https://image.token-recyclebin.com/v1 with gpt-image-2。这是一个第三方 OpenAI 兼容代理，按 token 计费，中文文字渲染较好。

用户私有数据（输入内容、生成的图）只在你的浏览器和上述供应商之间流动，不经过 skill2web 作者任何服务器。Key 仅写入你浏览器 localStorage，刷新页面保留，关闭浏览器不会上传。
